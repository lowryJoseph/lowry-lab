# Lowry Lab — Render-ready Creature Forge

This is the Creature Forge demo prepared for deployment to Render.

## Local
```bash
npm install
npm start
```
Open http://localhost:3000

## Render
The app reads Render's `PORT` environment variable and binds to `0.0.0.0`.
A `render.yaml` Blueprint is included, but you can also create a Web Service manually.

Build command: `npm install`
Start command: `npm start`

No database or environment variables are required for this demo.
