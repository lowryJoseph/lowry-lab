5. So what is the actual point?

Direct REST

The UI needs to know which API to call, which extra APIs contain related data, and how to combine the responses.

GraphQL facade

The UI asks for a Creature. GraphQL knows how the backend is organized and can keep using the existing REST services underneath.

Layperson bottom line: REST mode makes every customer learn the layout of the warehouse. GraphQL gives them a service desk: ask for what you need, and the desk finds it.
