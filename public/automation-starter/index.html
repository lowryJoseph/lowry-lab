CLONE → CONFIGURE → RUN

The whole onboarding story.

  1. 1

    Have Java 21 and Maven

    java -version
mvn -version
  2. 2

    Install the Playwright-managed browsers once

    mvn test -DskipTests
mvn exec:java -e \
  -Dexec.mainClass=com.microsoft.playwright.CLI \
  -Dexec.args="install chromium firefox webkit"
  3. 3

    Run the included test

    mvn test

    Chrome is the default. The test runs against the live Creature Forge architecture demo.

THE POINT

Start from working. Add complexity only when the problem earns it.

Version 1 is intentionally not a finished enterprise framework. It is a functional foundation: browser management, test lifecycle, page-object separation, and one real test. Reporting, API setup, configuration, parallel execution, CI, and other layers can be added one decision at a time.
